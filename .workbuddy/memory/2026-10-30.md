## 关键决策与理由

- **Java 25 而非 HANDOFF §7.1 的 21**：用户指定；虚拟线程 21 就有，25 是当前 LTS，Gradle 9.8.2 原生支持。
- **暂不引入 Spring Boot / Netty 运行时**：HANDOFF 写的是「Netty 原生 或 Boot 3 + WebFlux」，但 **Boot 3 不支持 class file 69（Java 25），得 Boot 4**。框架选型留到 §8 第 1 步（录制 golden 契约）之后，现在只留 netty/jackson 依赖在目录里备用。
- **遇到并修掉的坑**：`subprojects {}` 里用 `libs.xxx` 会报 `Extension with name 'libs' does not exist` —— 因为 delegate 换成了子项目，accessor 失效。解法：先在根作用域把要用到的 catalog 依赖取成本地变量，再在闭包里引用。

  `%.4level` 做不到 DEBG/EROR（只会截成 DEBU/ERRO）。

  教训：日志辅助方法包装 log 调用必然丢行号。

  `conversionRule` 用 `class` 不是 `converterClass`（否则 deprecation 刷一屏）；
